# Маршрут построен ✦

Бордово-золотой онлайн-оракул, придуманный как продолжение подарочной колоды «Маршрут построен» — **для тех, кому мало**.

## Что работает
- **56 авторских онлайн-карт, не повторяющих 16 печатных**: послание, ироничная фраза и вопрос к себе.
- **4 расклада**: одно послание, карта дня, три остановки, рейс в 2027.
- Выбор темы: путь, перемены, любовь, деньги, о себе, люди, ресурс, смелость.
- Сохранение на своём устройстве, кнопки «Поделиться» и «Ещё».
- Адаптация для телефона, без регистрации и серверной части.

## GitHub Pages

Сайт публикуется автоматически через **GitHub Actions** из ветки `main`. В настройках Pages источник — **GitHub Actions**.

Адрес для репозитория \`Tatakomotako/marshrut-postroen\` после публикации:
\`https://tatakomotako.github.io/marshrut-postroen/\`

**Важно:** QR-код на подарочной бумаге нужно печатать только после проверки открывающейся публичной страницы.

## Файлы
- \`index.html\` — доступная разметка интерфейса;
- \`style.css\` — оформление и мобильная адаптация;
- \`app.js\` — 56 карт и механика;

Это творческий метафорический инструмент для рефлексии, не предсказание будущего.

## Иллюстрированные карты — финальная установка

Весь комплект из **56 полноразмерных онлайн-карт** подготовлен единым ZIP-архивом `oracle_assets.zip`.
Файлы лежат в архиве как `assets/cards/01.webp` … `assets/cards/56.webp`, каждый 1024×1536 px.

**Для установки из ChatGPT**:

1. Скачай подготовленный архив именно с названием `oracle_assets.zip` (не PNG-архив для печати).
2. Открой https://github.com/Tatakomotako/marshrut-postroen/upload/main
3. Перетащи **один ZIP-файл** в корень репозитория и нажми **Commit changes**.
4. GitHub Actions запустит `Install illustrated cards from ZIP`: проверит ровно 56 WebP и добавит их в `assets/cards`.
5. `Publish travel oracle` автоматически обновит сайт. После успешного развёртывания проверь расклады на телефоне.

Больше не надо загружать 56 файлов вручную. **Не распаковывай архив перед загрузкой.**

Сайт использует полноразмерные изображения `assets/cards/NN.webp` по ID соответствующей онлайн-карты.
До установки изображения либо при ошибке загрузки сайт автоматически покажет существующую текстовую карточку, поэтому механика раскладов остаётся работоспособной.

Исходники PNG предназначены для сохранения и самостоятельного редактирования дизайна.
