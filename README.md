# Маршрут построен ✦

Бордово-золотой онлайн-оракул, придуманный как продолжение подарочной колоды «Маршрут построен» — **для тех, кому мало**.

## Что работает
- **72 авторские карты**: послание, ироничная фраза и вопрос к себе.
- **4 расклада**: одно послание, карта дня, три остановки, рейс в 2027.
- Выбор темы: путь, перемены, любовь, деньги, о себе, люди, ресурс, смелость.
- Сохранение на своём устройстве, кнопки «Поделиться» и «Ещё».
- Адаптация для телефона, без регистрации и серверной части.

## GitHub Pages

Размести сайт из ветки **main** и каталога **/ (root)**:
Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.

Адрес для репозитория \`Tatakomotako/marshrut-postroen\` после публикации:
\`https://tatakomotako.github.io/marshrut-postroen/\`

**Важно:** QR-код на подарочной бумаге нужно печатать только после проверки открывающейся публичной страницы.

## Файлы
- \`index.html\` — доступная разметка интерфейса;
- \`style.css\` — оформление и мобильная адаптация;
- \`app.js\` — 72 карты и механика;
- \`favicon.svg\` — иконка сайта.

Это творческий метафорический инструмент для рефлексии, не предсказание будущего.
